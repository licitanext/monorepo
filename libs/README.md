# libs/

Paquetes y librerías compartidas entre las aplicaciones del monorepo
(p. ej. modelos de dominio Dart reutilizados por la app, clientes de API,
o utilidades Python compartidas por servicios).

Cada librería es un paquete independiente con su propio `pubspec.yaml`
(Dart) o `pyproject.toml` (Python). Vacío por ahora.
