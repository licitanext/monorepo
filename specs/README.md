# specs/

Especificaciones de requisitos del producto siguiendo el estándar
**IEEE 830** (SRS). Cada spec describe un módulo o capacidad de LicitaNext
(p. ej. el pipeline de ingesta SICOP, el motor de match UNSPSC, o el sistema
de alertas de la app).

Las plantillas base (IEEE 830, ADR) viven en
[`../docs/templates/`](../docs/templates/). Vacío por ahora.
